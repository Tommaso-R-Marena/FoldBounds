# FoldBounds: complete exact GNM rank classification over 32,768 contact graphs

**Scientific status:** This is an independently checkable, mathematically exact result **within a specified Gaussian-network model (GNM)** built from an experimentally deposited ubiquitin reference structure. It is **not** an experimental folding breakthrough, improvement in observed mobility prediction, or claim of new mathematical priority. Its adversarial graph envelope is a conservative **superset** of contact patterns generated by physically realizable coordinate perturbations.

## Source and preregistered scope

- Public deposited **PDB 1D3Z ubiquitin solution NMR** model 1 (no motion labels used), `69` CA atoms, residue numbers `2..70`, using the same exact 0.001 Å reference fixture and archived-source integrity checker as parent PR #76. Source: `encore-similarity/encore` filtered public file `examples/experimental_ubq_ensembles/filtered_1D3Z.pdb`, Git blob SHA-1 `a438d36816e15647177e32d2eafa6aa9a0782747`.
- Graph: mandatory covalent chain bonds, and nonlocal contacts for residue index separation at least 3 and nominal distance strictly below 8 Å. Hypothetical Cartesian coordinate uncertainty ±0.05 Å per component, *not measured/calibrated NMR uncertainty*. Guaranteed and possible contacts use the conservative rational displacement bound `7ε/2 > 2√3 ε`, with **exact** squared-distance classification.
- Input has **15 uncertain nonlocal contacts**, yielding `2^15 = 32,768` possible assignments of independently chosen contact edges. Every such graph contains the backbone and therefore is connected.
- Prediction is the residue-specific *scalar GNM pseudoinverse diagonal* \(C_{ii}\), a model flexibility score, not a measured dynamical quantity. There are `69 choose 2 = 2,346` unordered residue rankings.
- **No sealed or blind protein target**, held-out NMR ensemble label, or registered RNase motion result was accessed or modified. Published RNase weighted-ANM blind failure remains a failure.

## Exact small-matrix reduction

For the *certain* connected graph define the integer **grounded matrix**

\[
B_0=n L_0+\mathbf1\mathbf1^\top,\quad B_0 N=dI,\quad d>0,
\]

where the untrusted proposer supplies integer \(N,d\) but the checker reconstructs \(B_0\) from the declared graph and independently verifies **all** \(n^2\) integer products. For each optional edge \(e=(u,v)\), let \(b_e=e_u-e_v\), and for a subset of present edges \(S\), collect columns \(E_S=[b_e]_{e\in S}\), and \(Q_S=N E_S\). Define the at-most-15-dimensional **integer matrix**

\[
M_S=dI+n E_S^\top N E_S .
\]

Then the exact Woodbury identity gives

\[
B_S^{-1}=\frac1d\left[N-nQ_S M_S^{-1}Q_S^\top\right].
\]

The GNM covariance is \(C_S=n B_S^{-1}-\mathbf1\mathbf1^\top/n\). The common positive scale and common translation-mode term do **not** change diagonal comparisons. This lets every comparison and rank-two Loewner bound be checked by integer arithmetic on the **dimension-reduced** \(M_S\), without calculating or verifying another full 69×69 inverse for each graph.

The `ReducedWorldCache` computes each proposed reduced inverse \(T/\delta=M_S^{-1}\) using an *untrusted* SymPy `inv_den()` provider, then independently verifies the exact integer identity \(M_ST=\delta I\), the sign \(\delta>0\), symmetry, dimension, and full crossproducts before use. The initial full inverse is independently verified against \(B_0N=dI\). The checker uses only integers for acceptance; it does not depend on floating point, matrix condition numbers, approximate residual thresholds, or unverified user-provided root finding.

For two residues \(i,j\), the exact sharp rank-two envelope for \(C_{ii}-C_{jj}\) across a graph Laplacian interval is checked with the integer discriminant \(s^2>\Delta\), as in parent PR #76. The continuum Loewner/spectral theorem is standard semidefinite matrix analysis; this project has **not** proved its algorithmic refinement in Lean.

## Why the proof covers all worlds without brute force

The untrusted numeric proposer explores all 32,768 graph assignments using Gray-code floating-point Sherman-Morrison updates to *suggest* stable signs, unstable pairs, their 19 counterexample masks, and a compact conditional splitting tree. **None of its floating-point results is accepted by the checker.** The checked input `research/gnm_1d3z_complete_worlds.json` contains only structural claims and the proof-tree/counterexample proposal; its `proposer_statistics` is ignored for acceptance.

The independent checker:

1. Reconstructs source-derived certain/possible graphs and canonicalizes the 15 optional edge ordering; rejects a mismatched proposal.
2. Re-checks the 1,947 prior signed orders using all eight exact prior Boolean cases and independently checked reduced inverse identities.
3. Traverses **both children** of every proposed split, forbidding reassigning an already-decided optional edge. It accepts a leaf only when the exact PSD rank-two interval bounds prove *all* 33 proposed additional signs throughout **every remaining unresolved edge assignment**.
4. Reconstructs the 19 proposed **complete** Boolean networks and verifies their exact graph inverses, checking both strict sign directions for each of the 366 asserted non-invariant pairs.
5. Enforces that the prior, new invariant and reversing sets are **pairwise disjoint** and together contain **all 2,346** residue pairs. Missing pairs, forged signs, invalid masks, nonexhaustive branches and corrupted inverse matrices cause an explicit failure.

The two terminal proof classes—signed leaf rank intervals and opposite-sign complete-network witnesses—constitute a **complete, independently replayable finite Boolean classification**. Proving that an *actual physical coordinate box* can realize each counterexample graph would require additional coupled geometric constraints. The theorem does not assert that.

## Scientific limitations and next gate

This is a genuine **complete mathematical certificate for the chosen GNM graph uncertainty model**, demonstrably using actual deposited protein coordinates. It is not an original physical law and does not improve a predictor's empirical motion accuracy. In particular:

- 1D3Z consists of NMR structure models, **not** independently measured equilibrium fluctuation trajectories; these conformers should not be treated as dynamical ground truth.
- The ±0.05 Å coordinate uncertainty is an **illustrative choice**, not measured NMR coordinate accuracy.
- Independent Boolean contact assignments can violate the shared geometry of one perturbed structure, so the 366 reversing pairs are graph-envelope vulnerabilities, *not necessarily experimentally attainable fluctuations*.
- Proving a 1,980-pair invariant property across the **over-approximating** contact graph envelope does also imply those same pairwise model rankings cannot reverse within any geometrically feasible subfamily it contains, conditional on this graph model and coordinate box.
- The reduction uses classical Woodbury, graph Laplacians and rank-two spectral certificates; no theorem priority or new folding mechanism is asserted. Existing Lean CI does not kernel-check this new Python verifier or its 1D3Z bytes.

The most consequential next scientific study is genuinely prospective validation on an independently reserved protein with experimentally measured fluctuations and physically calibrated uncertainty; only that could support a new biological prediction claim.
